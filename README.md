CSOAI Ltd — public name Council of AI (UK Companies House 16939677, London; second domain csoai.org) — is an independent AI-governance MEASUREMENT body: "measurement, not certification". It publishes the living GSPC board (Governance · Safety · Provenance · Continuity) as a keyless, CORS-open JSON API, Ed25519-signed measurement cards verifiable offline against a did:web:csoai.org key document, a Merkle public root with inclusion proofs, an EU AI Act Article 50 machine-marking detector, and a dated corrections ledger. The estate is exposed to agents three ways: a 141-operation OpenAPI 3.1 contract at https://councilof.ai/openapi.json (plus a 7-operation read-surfaces spec), a remote MCP server at https://councilof.ai/mcp (13 tools with anonymous tools/list; npm stdio twin csoai-gspc-mcp; MCP Registry io.github.CSOAI-ORG/gspc), and an A2A v1.0 agent card at /.well-known/agent-card.json with eight skills. Ten REST doors and four MCP tools are metered per artefact by x402 (USDC on Base, amounts only inside the 402 challenge); the board, verification and every preview are free and need no account.

**Areas:** AI Governance · AI Measurement · AI Safety · EU AI Act · Compliance · Provenance · Agents · A2A · MCP · x402 · Agentic Commerce · Agent-Native

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Council of AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
